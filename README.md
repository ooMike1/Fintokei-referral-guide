# Fintokei Referral Guide

Bilingual static site for GitHub Pages.

## Files
- `index.html`: English guide
- `es.html`: Spanish guide
- `sitemap.xml`: sitemap for the planned GitHub Pages URL
- `robots.txt`: allows public crawling and points to the sitemap
- `.nojekyll`: publish files as static assets without Jekyll processing

## Planned URL
https://oomike1.github.io/fintokei-referral-guide/

This URL assumes the public repository is named `fintokei-referral-guide` under the GitHub account `ooMike1`. If you choose another repository name or a user/organization site repository, update the canonical URLs, `robots.txt`, and `sitemap.xml` before publishing.

## Publish
1. Create a **public** repository named `fintokei-referral-guide` under `ooMike1`.
2. Upload all files from this folder to the repository root on the `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
4. Wait for GitHub Pages to deploy, then verify the published URL.
5. If the final URL differs from the planned URL above, replace all canonical, hreflang, Open Graph, sitemap and robots URLs with the real URL and commit the changes.
6. Add the final URL to Google Search Console and Bing Webmaster Tools.

## Accuracy and disclosure
The page includes the personal referral URL provided by the site owner and discloses that the owner may receive a benefit. Referral terms can change; re-check Fintokei's official rules before changing the offer text.
