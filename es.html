Preguntas frecuentes

¿REF-5937GLDD es un código de descuento público?

Es el código de referido incluido en mi enlace personal de Fintokei. No puedo garantizar por mi cuenta su validez o elegibilidad para todos los usuarios; comprueba el resultado que muestra la página de pago de Fintokei.

¿Quién puede utilizar el descuento?

Las condiciones publicadas indican que el descuento se aplica a la primera compra de un Challenge del cliente. Consulta las reglas oficiales para conocer todos los requisitos.

¿Reciben una recompensa ambas personas?

La información publicada por Fintokei describe una recompensa de 300 XP del Loyalty Program para cada participante cuando se completa una compra elegible, sujeta a las reglas del programa.

¿Las compras de vouchers cuentan?

Las condiciones publicadas del programa Refer a Friend indican que las compras de vouchers no cuentan para cumplir los criterios de compra.

¿Esta es una página oficial de Fintokei?

No. Es una página informativa independiente mantenida por un participante del programa de referidos. La web y el soporte oficiales de Fintokei son las fuentes autorizadas para consultar las condiciones vigentes.

¿Un Challenge de Fintokei está libre de riesgo?

No. Puedes perder el importe pagado por el Challenge y no se garantiza cumplir los criterios de evaluación ni recibir una recompensa. Lee las condiciones aplicables antes de pagar.
